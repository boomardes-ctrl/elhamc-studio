# إلهامك | استوديو تصميم وهوية بصرية

موقع إدارة مشاريع تصميم متكامل مع بوابة عملاء ولوحة إدارة.

## التشغيل السريع

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل الموقع (تطوير)
npm run dev

# 3. افتح المتصفح
# http://localhost:3000
```

## المميزات

- ✨ **SQLite** - قاعدة بيانات محلية تثبت البيانات بعد إعادة التشغيل
- 🎨 **تصميم فاخر** - Glassmorphism, Animations, Dark/Light mode
- 👤 **بوابة العميل** - دخول آمن بكلمة مرور، متابعة المشاريع، دردشة، ملفات
- 🔧 **لوحة الإدارة** - إدارة المشاريع، الخدمات، النصوص، معرض الأعمال، النسخ الاحتياطي

## بيانات الدخول

- **بوابة العميل**: استخدم كلمة المرور الخاصة بالمشروع (مثال: `elh9482`)
- **لوحة الإدارة**: كلمة المرور الافتراضية `5398538`

## ملاحظات

- قاعدة البيانات في ملف `database.sqlite` (لا يتم مسحها عند إعادة التشغيل)
- الملفات المرفوعة تحفظ في مجلد `uploads/`
- تم استبدال `db.json` بـ SQLite لحل مشكلة فقدان البيانات
